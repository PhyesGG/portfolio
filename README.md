# Portfolio - Abidi Mohamed

Portfolio personnel presentant mon parcours en tant qu'etudiant en BTS SIO option SISR (Solutions d'Infrastructure, Systemes et Reseaux) en alternance. Ce site met en avant mes competences techniques, mes projets professionnels et ma veille technologique sur l'integration des IA generatives en environnement d'entreprise.

## Contenu

- **Presentation** : Mon profil et mes objectifs professionnels
- **Competences** : Systemes (Windows Server, Linux, Active Directory), Reseaux (VLAN, PfSense, TCP/IP) et autres technologies
- **Projets BTS SIO** :
  - E6 - Migration Active Directory (150 postes vers Windows Server 2022)
  - E6 - Securite Reseau (Segmentation VLAN, PfSense)
  - E5 - Gestion des Tickets GLPI
- **Veille Technologique** : Integration et securisation des IA generatives (LLM) en entreprise
- **Articles** : Blog technique sur les sujets actuels

## Fonctionnalites

- Design moderne et responsive
- Animations fluides avec Framer Motion
- Articles techniques automatises
- Carousel de projets
- Navigation intuitive

## Stack Technologique

- **Framework** : Next.js 14
- **Langage** : TypeScript
- **Styling** : TailwindCSS
- **Animations** : Framer Motion
- **Composants UI** : Headless UI, Lucide React
- **SEO** : Next-SEO
